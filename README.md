# Axon Global Services

Static board brief. HTML and one stylesheet, generated by `site.py`.

```sh
python3 site.py
```

Output is `site/`. Reports are `reports/header-scan.json` and `reports/page-weight.json`.

GitHub Pages, when an owner turns it on, should use the default `github.io` host. This repo has no `CNAME`. The workflow deploys the `site/` directory from `main` with GitHub Actions. It does not change repository settings.

The private reference repo `undercl0ck/golden-ratio-web-design` was not readable from the account that built this site.
